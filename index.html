How to Use This Family Tree
A guide to exploring and contributing to our family history
🌳 Family Tree Tab
The main view shows the entire family across all generations. Each box is one person.
  • Click a person to see their full details in the side panel (parents, spouse, children, siblings).
  • Collapse / expand a person's children using the small ▾ / ▸ button at the bottom-right of their box, or by double-clicking the box. A collapsed box shows how many children are hidden.
  • Drag empty space to move around. Scroll / pinch to zoom in and out.
  • Use ⊕ All / ⊖ All to expand or collapse the whole tree.
  • The search box (top of this tab) finds anyone by English or Tamil name; the small map (bottom-right) shows where you are; the legend sits at the bottom-right as a small Legend ▸ button — click it to expand the flags, colours and DNA key, and click again to tuck it away so it doesn't cover the tree.
  • Use ⎘ PDF (admin) to print or save the tree as a PDF; the legend and the "Presented by" credits are added to the bottom of the page automatically.
🔍 Searching
On the Family Tree tab, type any name (English or Tamil) in the search box at the top of that tab. Matching people are highlighted in the tree and listed in a dropdown — click a result to jump straight to that person. Branch View has its own separate search box.
🧬 Relationship Finder
Open any person’s details in the side panel, scroll to Relationship Finder, and start typing another person’s name. Pick them from the list and the tool tells you exactly how the two are related — parent, sibling, cousin, grandparent, or related by marriage.
🧵 Branch View Tab
Search for a person to see just their branch — their spouse(s), all their descendants, and their siblings — laid out as a clean tree.
  • Click any person in the branch to see their details in the side panel — this stays on the Branch View tab. Use ▼ Show as branch root in the panel to re-centre the branch on that person.
  • Collapse / expand any person's children with the ▾ / ▸ button on their box. Click the Siblings heading to show or hide the list of siblings.
  • ↓ Export Branch (CSV) downloads just this branch — the person, their spouse(s) and all descendants — as branch_data.csv.
  • ⎘ Print Branch prints or saves the branch as a PDF (A3 landscape), with the legend and credits at the bottom.
  • The legend sits at the bottom-right as a Legend ▸ button you can expand or minimise, the same as on the Family Tree tab.
  • An administrator can set a default person so Branch View opens to a chosen family member; otherwise it opens with the search box ready.
✉ Contact Us Tab
Found something to add or correct? Use this form. Fill in your name and email, then add a card for each person you want to add or update — each card has all the same fields as the tree (name, dates, places, parents, spouse, DNA, photo, and so on). You can add up to 10 people in one submission. An administrator will review and apply your changes.
📱 On Mobile
The tree works on phones and tablets. Use one finger to pan and two fingers to pinch-zoom. On a phone the details panel starts closed so you see the whole tree — tap any person to open their details. You can add this page to your home screen for an app-like experience.
🔒 For Administrators
Click the 🔒 Admin button (top-right) and enter the password to unlock editing, data import/export, GEDCOM export, validation checks, and configuration. Notes on editing:
  • When adding a child from a person, that person and their spouse are pre-filled as the parents, and the country is copied across — adjust as needed.
  • The Father, Mother and Spouse fields are type-to-search: start typing a name and pick from the short list instead of scrolling.
  • Generation can be set manually to override the value auto-calculated from parents; leave it blank to auto-calculate.
  • On the Admin tab you can set the Presented By line (use a line break for two lines, which also shows on printed PDFs) and the welcome-screen credits, set a Branch View default person, and configure the contact-form email and donation links.
  • Tab visibility now covers Family Tree, Contact Us, Help, Version Updates and Support. Branch View is always visible, as it is the main way visitors explore the tree. You always see every tab while logged in.
  • Download config.json saves every setting (with explanatory notes kept in the file), and Import Config restores all of them from a saved file. Re-upload all files to publish changes for everyone.
  • Recalculate Generations (Admin tab) recomputes everyone's generation from the family links — handy after adding a new ancestor at the top of the tree. It updates the view only; review it, then Export CSV and re-upload to publish. Generations don't update automatically when you add a parent, so run this after such a change.
🔒 Password Management
📝 Welcome Screen Text

Set the presenter line and the contributor credits shown on the welcome screen (and on printed PDFs). Save, then Download config.json and re-upload to publish for all.

🧵 Branch View Default

Optionally set a person that Branch View opens to by default. Pick a generation to narrow the list, then choose the person. Leave as "none" for Branch View to open with the search box ready. Saved in config.json as the person's id (e.g. p417); an exact, unique person name also works if you edit the file by hand. Save, then Download config.json and re-upload to publish.

🗂 Tab Visibility (Publishing)

Choose which tabs the public sees. Branch View is always visible — it is the main way visitors explore the tree. You (logged in via the lock button) always see every tab regardless of these settings. After changing, click Download config.json and re-upload all files to publish the change for all visitors.

✉ Contact Form Email Configuration
📖 Step-by-step setup instructions (click to expand)
  1. Go to emailjs.com and create a free account.
  2. Add an Email Service (e.g. connect your Gmail). Copy the Service ID (looks like service_xxxxxxx).
  3. Create an Email Template. In the template body, include these variables exactly:
    From: {{from_name}} ({{from_email}})
    Phone: {{phone}}
    About: {{about_person}}

    People to add/update:
    {{people_data}}

    Notes: {{notes}}
    Set the template’s "To Email" to your own address. Copy the Template ID (template_xxxxxxx).
  4. In EmailJS Account → General, copy your Public Key.
  5. Paste all three IDs plus your admin email below and click Save. The Contact Us form will then email submissions directly to you.
❤ Support / Donation Page

Show an optional donation page where family members can contribute a few dollars. Provide a PayPal.Me link and/or a Stripe Payment Link. These are simple URLs — no API keys are stored in this file, which keeps it safe to publish.

How to set up PayPal: Go to paypal.me and create your link, or create a Donate button at paypal.com/donate. Copy the URL here.
How to set up Stripe: In the Stripe Dashboard, go to Products → Payment Links → create a link (set your own amount or "customer chooses"). Copy the buy.stripe.com URL here.

↻ Generations

Recompute every person's generation from the family links. Parents set the generation; people with no parents inherit from their spouse. Useful after adding a new ancestor at the top of the tree. This updates the on-screen view only — review it, then Export CSV and publish to make it permanent. Any genuine cross-generation marriages will appear in the Validation tab.
